# 页面规矩（按页面类型）

| 类型 | 结构 | 必须有 | 常见错误 |
|---|---|---|---|
| 列表页 | 筛选区 → 操作按钮行 → 表格 → 分页 | 空状态；批量按钮常驻、未勾选时置灰；行操作 ≤ 3 个，多的收进「更多」 | 一个单元格塞两个字段（「创建人 / 时间」）；筛选区下面堆统计数字卡 |
| 表单页 | 分组标题 → 字段（标签在上）→ 底部固定「保存 / 取消」 | 必填标星；失焦即校验并写出原因；能预填的预填 | 提交后才一次性报错；让用户手填系统算得出的值 |
| 详情页 / 抽屉 | 标题 + 状态 → 关键信息 → 明细表 → 操作日志 | 状态用文字标签；操作按钮和状态联动（已完成的单不显示「取消」） | 用居中弹窗展示长明细 |
| 看板页 | 时间范围 → 3–5 个核心数 → 趋势图 → 明细入口 | 每个数写口径（怎么算）和更新时间 | 堆十几个指标；没有口径说明 |

## 通用
- 危险操作（删除、取消订单、退款）一律二次确认，确认框写清「会发生什么」。
- 金额右对齐，带币种；时间统一格式 `YYYY-MM-DD HH:mm`。
- 所有示例数据旁标「示例」。
